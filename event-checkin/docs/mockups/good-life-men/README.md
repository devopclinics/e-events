# The Good Life — Men and Young Men

Design-only mockup for a reusable Festio Live Experience workflow. This is not a staging screenshot and no workflow has been imported.

## Source lock

The content and sequence come from `Harvad 75yrs- goof life for men.pdf` (12 pages). The attached implementation brief is used only for interaction and visualization direction. The mockup does not add questions, subject matter, scripture, research, or commitments.

## Reusable configuration direction

- Content remains workflow data: titles, copy, options, video reference, timer duration and presenter notes.
- Visual behavior remains renderer data: `donut`, `influence_orbit`, `connection_gauge`, `life_wheel`, `legacy_podium`, `generational_mirror`, `aggregate_fallback`, and `commitment_tiles`.
- Scene 09 must use the grouped view only when participants explicitly provide permitted life-stage data. It must never infer age. Otherwise it renders the aggregate fallback.
- Percentages and response totals in this mockup are sample data only.
- Presenter timer controls remain separate from the public display.

## Review artifact

- `experience-mockup.png` — complete scene board for design approval.
- `experience-mockup.html` — editable source for the board.

After approval, the next phase is implementation and staging import. Production promotion requires a separate explicit approval after staging validation.
