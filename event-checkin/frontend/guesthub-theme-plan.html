Architecture

How the pieces connect

The Hub theme system has two axes today: layout (tabbed vs stacked) and colors (from the event's global design palette). We're adding a third axis — visual style — which bundles a layout type, a color preset, CSS overrides, and a font suggestion into a single selectable option.


When an organizer picks a hub theme in Design Studio, it writes hubStyle to theme_config. InvitePage reads designTheme.hub_style and applies the matching CSS class. The 10 new styles extend this exact flow with no API or DB changes needed.

DesignStudioRedesignPage.jsx
→
api.saveEventDesign()
↓
writes theme_config.hubStyle + optionally theme_config.colors
design-service DB
→
GET /api/invite/{id}
↓
returns design_theme.hub_style + design_theme.colors
InvitePage.jsx — GuestHub
→
fh-hub-style-{id}
↓
CSS class scopes all visual overrides for that theme
