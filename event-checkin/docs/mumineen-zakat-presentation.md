# Zakat — When wealth becomes well-being

A 14-slide, approximately 12–15 minute educational presentation for Mumineen Academy.
Published entry: `/presentations/mumineen-zakat/`.

Includes cinematic 3D artwork, forty-token rate explanation, an illustrative calculation,
eight recipient categories, audience discussion, and speaker notes. Financial examples
are explanatory and collect no audience data. It does not certify the academy's general
campaign as Zakat-eligible; asset-specific rulings and institutional uses need qualified
review. Religious sources are linked on the relevant slides and in the final reference slide.

The HTML deck supports keyboard arrows, Home/End, N notes, O overview, B blackout,
and F fullscreen. PDF and PowerPoint downloads contain the same 14 slides; PowerPoint
slides use high-resolution rendered artwork with notes preserved in the notes pane.
`SPEAKER-NOTES.md` is also included. `?embed=1&page=N` selects a projector slide.

The native Presenter materials workspace recognizes this first-party deck and sends a
new embedded page URL on Next/Previous; external links and existing PDF behavior
remain unchanged. Issuance, certificate, donation and messaging logic are untouched.
The library entry is event-scoped and does not automatically switch an active display.

Validation: slide bounds, 14-page PDF, 14-slide PowerPoint, speaker notes, reveal actions,
source references, keyboard controls, mobile overflow, native presenter page navigation,
first/last boundaries and blackout. Tests use local fixtures and no live messages/payments.

Artwork: generated with the built-in image_gen tool. Visual metaphor, not religious
imagery or documentary photography. Prompt: create a wide cinematic 3D still for an
educational Zakat presentation; a delicate olive tree growing on a warm ivory stone
island, small unmarked champagne-gold discs on a curved pathway, entirely in frame at
the right, clean dark forest-green negative space on the left, museum-quality maquette,
realistic limestone, soft warm light, dignity and hope; no lettering, logos, people,
holy figures, sacred objects, interface, or watermark.
